# Data Force Solutions Landing Page

Landing page for the **Data Force Solutions** project.

## Project Structure

- **Name:** dataforcesolutions
- **Version:** 0.0.0
- **Type:** Module
- **Private:** true

## Installation and Setup

Before starting, install all dependencies:

`npm install`

To run the development server, use the following command:

`npm run dev`

To build the project for production, run:

`npm run build`

To preview the production build, use:

`npm run preview`
